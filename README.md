# Exercícios de Lógica de Programação com Python 

Este repositório foi criado para armazenar os meus primeiros algoritmos desenvolvidos durante as aulas de lógica no **SENAI Dendezeiros**.

## 📌 Conteúdos
- **Variáveis e Operadores Matemáticos:** Exercícios práticos de fixação (ex: cálculo de faturamento de padaria e poupança automática).
- **Entrada e Saída de Dados:** Manipulação de inputs e formatação de prints.
